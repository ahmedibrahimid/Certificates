## Maintaining this index

`metadata/certificates.csv` is the single source of truth. Adding a certificate is a manual, three-step process — no tooling beyond Python and no interpretation required:

1. Copy the PDF into the category folder that matches the certificate.
2. Add one row to `metadata/certificates.csv`.
3. Run `python scripts/generate_readme.py` and commit.

The full procedure — the filename convention, how to pick a category, and what every column means — is in [docs/ADDING-A-CERTIFICATE.md](docs/ADDING-A-CERTIFICATE.md). Run `python scripts/generate_readme.py --check` at any time to validate the CSV without rewriting this file.
